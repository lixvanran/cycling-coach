
# 如何确定无氧/乳酸阈值心率

### LT-心率训练

无论是功率、心率还是体感训练，都要找一个参考点（reference point）。心率训练的一个参考点就是最大心率。但公式计算不准确，实际测量太辛苦。实际使用中，也并不准确。乳酸阈值（lactate threshold）：LT，也就是运动员常说的红线（redline），是一个很好的参考标准。而它占最大心率的比例差异很大，可能是70-90%。体能越好，比例越高。【举例：两个人的最大心率都是200，但一个人的LT在70%，另一个在90%，相同心率下训练差异很大。】

确定LT主要有两种方法。
- 代谢测试（metabolic testing）：对于发现运动员的体能，准备计划非常有用。测试中还可以收集需要数据。此外，功率区间、脂肪和碳水的利用率，以及对应的RPE，对于教练都很重要。每个主要周期开始进行测试，可以检测训练效果。
- 实地测试（field test）：实验室的测试非常准确，可以控制各种因素，保证测试结果的值是来自体能变化。但价格昂贵。1-2周测试一次，很难承受。另一种更加简单的测试方法就是实地测试。测试过程类似，但是自己要控制外部和内部因素。

测试要求：测试前必须保证充分的休息。测试前3-5天降低负荷。

确认测试结果：训练过程，检查自己的心率，确认测试结果是否准确。LT时呼吸应该加深（通气阈值ventilatory threshold VT）。LT和VT同时发生。另外还可以用RPE检测，应该在7。上面的两种测试方法，也可以相互检测。

### 计时赛阈值（TT）

有一个数值很重要：在1小时计时赛中，你能保持的最大心率的百分比是多少？

传统认为运动员的计时赛阈值是最大心率的85%。这个说法有点保守。强健运动员的这个数值接近最大心率的92%。这个一小时92%最大心率的阈值在自行车中相当于40公里的个人计时赛。超过这个距离，阈值就会降低。而对于短距离比赛，阈值则更高。举一个极端的例子，横跨美洲大陆（RAAM）骑行的车手在比赛开始后1-2天后就只以最大心率60%的心率继续比赛。场地冲刺手在200米的比赛中全程保持最大心率。

这些百分比适合于休息充分，身体强健的运动员；而且温度适宜，海拔是水平面。如果状况不佳、疲劳、寒冷或在高海拔比赛，心率百分比都要更低。

### 阈值的不同定义

无氧阈值训练的概念源自F. Conconi博士对Francesco Moser的训练方法，让他在1984年1月19日创造了50.808公里世界一小时记录，1月23日再次提高到51.181公里。运动科学家和生理学家对阈值的定义并不相同。无氧阈值与计时赛阈值的概念也不相同。
