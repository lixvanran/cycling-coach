
# 使用骑行台训练的优缺点

### 优点
- 环境更可控（天气、温度）
- 专注骑行训练
- 环境安全（交通、地形、天气）
- 不用担心和其他人骑行的问题
- 用分利用有限的时间
- 方便练习踩踏等技术
- 方便观看学习视频

### 缺点
- 缺少实际路感
- 车辆操控要求下降（滚筒骑行台有一定训练效果）
- 空气流通差，容易出汗，核心温度升高快
- 长时间骑行比较枯燥
