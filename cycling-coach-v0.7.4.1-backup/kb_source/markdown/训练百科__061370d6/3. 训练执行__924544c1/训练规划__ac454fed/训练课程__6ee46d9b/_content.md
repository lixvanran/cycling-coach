
# 训练课程

### 训练课的结构

一节训练课的结构其实很简单。通常只有三个部分：热身、主体和冷身。其中，主体部分是此次训练的核心内容。但是热身和冷身同等重要。自我指导的运动员很容易跳过这两个部分。作为教练员则要特别提醒他们不要这样做。

在解释这三个部分之前，我们可以记忆一下它们的英文缩写，在编写训练课程时，可以节省时间。

• 热身（warm up，WU）

• 主体（main set，MS）

• 冷身（cool down，CD）

热身（WarmUp）

热身的目的是让运动员的身体和思想做好运动的准备。这一步非常关键，充分热身可以让运动员发挥出更好的成绩。很多新手则不愿意热身，认为这样会浪费体力。这是个误解，热身可以提高运动表现，还可以降低受伤的几率。

热身的具体流程因人因训练而异。一般的原则就是让训练要使用的肌肉逐渐热起来。而一个简单的指标就是心率。从轻松的运动开始，让心率逐渐上升，达到或接近训练主体的强度。一个检验热身是否足够的传统方法，就是热身好微微出汗。

热身的时长通常是10-15分钟。如果训练主体的时间短、强度高，则可能需要较长的热身时间，热身的强度也要拉高。相反，如果是一次2区有氧耐力训练，可能只需要热身到2区的心率就可以开始正式训练内容了。

热身流程示例：

5分钟1区→5分钟2区→3组1分钟高踏频→轻松2-3分钟

冷身（CoolDown）

冷身的目的是让运动后的身体逐渐恢复到平静状态，而不是戛然而止。这样有利于身体的恢复，保护身体不受伤害。因此，和热身一样，提醒运动员，特别是在高强度的间歇训练之后，一定要做冷身。

冷身的过程和热身差不多，或者理解为相反。逐渐降低强度，减小身体输出。我们仍然可以使用心率作为冷身的指标。冷身的时长一般为5-10分钟。强度在1-2区。注意提醒运动员，冷身是尽量保持正常的踏频。

冷身流程示例：

2区5分钟→1区5分钟。

训练主体（Mainset）

训练主体，是一节训练课的核心内容，通常也就是你要强化的骑行能力。一般来说，一节训练课只专注于一项能力或二项能力，通常是一些综合训练，否则不建议刺激三项或更多的能力。

前面已经讲过训练强度区间，以及每个区间对应的骑行能力。表格的最后一列还有一个时长，当时我们并没有特别说明。现在来复习一下这张表格，讲解如何利用这张表格来安排训练课的主体。

在设计训练课主体时，大致分为3个步骤：

## 确定训练目标：确定这次课程练什么。

## 确定训练强度：在表中找到相应的强度区间。

## 确定训练形式：是连续骑行还是间歇形式。一般来说，除了1-2区以外，其他区间都会采用间歇的模式。

## 确定间歇时长：单次时长就是表格中的时长。新手通常选择较少的时长，而老手则可能需要更长的单次训练时长。当然，训练时长也可以根据训练/比赛需求来决定。

## 确定间歇次数：我们可以参考下表，查看最后一次间歇的功率下降了多少。如果下降比例如何下表，则停止间歇。如果是第一次做训练，我们可能无法准确预测间歇的次数，需要尝试安排。有条件的话，在运动员进行训练时监控数据。然后在下一次训练课中调整。

## 确定间歇的休息时长：间歇训练的休息时间也非常重要。合理安排休息，可以保证间歇训练的有效性。常见的间歇休息时长可以参加下表。

举个例子，一个新手想要提高FTP。他的FTP目前是150w。我们在设计课程时，根据上面讲的内容，确定了训练目标是提高FTP，对应的强度区间是4区。四区的最短间歇时长是10分钟，休息间歇是5分钟。根据经验，新手第一次大概可以做20分钟的FTP输出。因此，这节课最终写出来就是：

标题：FTP间歇训练2×10分钟

WU：热身10-15分钟，心率逐渐提高到3区。中间插入3组1分钟高踏频。

MS：2×10分钟FTP强度，中间休息5分钟。

CD：1区冷身5-10分钟。
