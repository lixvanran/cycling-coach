
# 训练前设置好你的训练工具

如今大家都会用到很多智能训练工具、APP。作为训练工具，数据的准确性非常重要。保证数据准确的前提条件之一就是正确设置相关信息。需要正确设置的常见信息包括：
- 性别
- 年龄
- 心率：最大心率、静息心率、阈值心率
- 功率：FTP
- 训练区间：基于心率、功率、速度、配速等的训练区间
- 器材信息：车辆信息、锁鞋信息
