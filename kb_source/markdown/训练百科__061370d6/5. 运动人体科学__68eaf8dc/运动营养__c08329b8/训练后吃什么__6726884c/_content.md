
# 训练后吃什么

### 训练后吃什么
- 训练后金枪鱼或花生酱三明治。芝士也不错。
- 天冷要多吃。
- 运动后半小时，至少摄入100-150g的碳水化合物
- 多日赛（stage racer）：每个赛段的最后一个小时吃半个蛋白质棒，恢复饮料中也要有蛋白质。睡前要喝恢复饮料。
- 取决于当天训练内容：如果是轻松的有氧课建议在训练过程中完成主要的营养补给（主要是糖类的补充）如果是强度课，训练后需要大量的摄入糖类。
