
# 🍞 训练的组成

![image.png](attachments/945f4864-902b-41a5-a2d6-882afb1d6c90.png)

对于一名运动员/车手来说，训练大体包括以下几个方面：
- 车上训练 指骑车进行的训练内容，也就是一般人认为的“训练”。可以分为有氧训练、无氧训练（也有强度其他分类方法），以及技战术训练等。
- 车下训练 指除了骑车以外的训练内容，主要是针对身体基本功能和一般运动能力的训练，主要包括身体的矫正、活动能力恢复、核心和力量训练等。通过这些训练，可以避免身体受伤，提高专项（骑行）能力。
- 营养 这些是我们的生存的基本和能量来源，也是保证运动表现的基础。主要包括日常的吃、喝，以及训练和比赛中的补给等方面。有时候也会涉及营养补给品、保健品的使用。
- 恢复 俗称休息，主要还是睡觉。职业运动员一天可能要睡10个小时，还不包括中午小憩。身体恢复的同时，还包括精神恢复。促进身体恢复的常见的方式包括按摩、洗澡、晒太阳（发呆）、聊天等等。
- 伤病康复 身体是运动员的本钱。运动损伤或其他伤病会影响运动表现和运动员的发展。预防损伤永远是第一步。但是伤病在所难免，因此及时、正确的治疗、康复也非常重要。
- 数据分析 数据分析是训练的重要组成部分。不分析数据，就是在瞎练。如今，可供分析的训练数据非常多，例如功率、心率、踏频等等。撰写训练日记，也可以算是对当日训练的一种主观记录和分析。
- 心理训练 这是经常被忽略的训练内容，但是它的重要性无法替代，占据所有训练内容的50%。心理训练的内容非常丰富，主要包括自律、自信、毅力等。高强度训练前的心理建设、训练后的精神放松，以及比赛战术的执行思路，也都属于心理训练。
