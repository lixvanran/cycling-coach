# Cycling Coach Mobile

> 状态:**占位** — V1.0+ 启动

## 选型待定(优先级)

| 方案 | 复用 web | 性能 | 包大小 | 适合 |
|------|----------|------|--------|------|
| **PWA**(Web App) | ✅ | 优 | 0 | MVP / 不想写 native |
| **Capacitor** + Web | ✅ | 中 | ~20MB | 短期(用现成 web) |
| **React Native** | ❌(新写) | 优 | ~30MB | 已有 RN 经验 |
| **Flutter** | ❌(全部 Dart) | 优 | ~25MB | 跨端战略 |

**建议先 PWA**(Vite + service worker + manifest),V1.0+ 再决定 native。

## 关键场景(什么时候需要)

- 边骑车边看实时数据(HR / 功率 / 踏频)— 必须有手机
- 离线使用 — 户外没网
- 后台上传 FIT — 从码表自动同步
- 推送提醒 — 训练计划 / 恢复提醒 / 比赛倒计时

## 何时启动

- 短期:**不做**(V0.x 聚焦核心训练 / AI)
- 中期:V0.5+ 至少做 PWA(零成本)
- 长期:V1.0+ 视用户量决定是否上 native
