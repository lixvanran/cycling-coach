
# 概述

公路车运动作为一项耐力运动，累积时长和里程是最基本的训练方式。随着运动科学的进步和训练工具的问世，公路车训练变得越来越有章法、规则。

从最早依靠体感来训练，到现在根据功率来安排训练负荷，让训练从一种感觉到可以量化、可视化地安排执行，可以称得上是天翻地覆的变化。

去高原来提高身体的血氧能力，已经被专业车手使用多年。各种室内模拟训练工具，大大降低了训练的成本，也让日常的训练变得更加多样。

无论训练方式方法如何，但是训练的基本原理并没有变化。只不过，适合自己的方法，可以大大提升训练效率。
