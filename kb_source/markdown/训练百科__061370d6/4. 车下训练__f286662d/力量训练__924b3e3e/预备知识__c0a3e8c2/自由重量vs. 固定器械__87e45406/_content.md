
# 自由重量vs. 固定器械

### 自由重量vs. 固定器械

### 自由重量（free weight）

自由重量，主要是指哑铃和杠铃。它们是力量训练的最基本器械。由于没有支架辅助，做自由重量的练习，对身体的平衡稳定能力要求更高，自由重量训练对稳定肌的激活要强于固定器械训练。

杠铃杆的有多种规格，主要分为直杆和曲杆。长度从1.5米到2.2米不等。奥林匹克标准杠铃杆的长度为2.2米，重量为20公斤。部分商业健身房配备的女子杠铃杆重量为15公斤。初次以外杠铃杆还有软杆与硬杆之类的区别。

杠铃片的重量范围可以从1公斤到25公斤。

哑铃的重量规格也很多，主要有固定重量和可调重量两种。单片重量从0.5-3公斤。

做某些自由重量的练习时，可能需要平凳或其他平台来辅助，或者是卧推架，深蹲架等装置。

自由重量的优点：

l 动作自由，可以更加贴近竞技运动中的模式，从而对专项有更多的迁移效果。

l 需要身体的协调和平衡，从而加强相应能力，需要激活更多稳定肌，提高关节稳定性。

自由重量的缺点：

l 动作以重力为对抗力量，可能无法有效刺激到目标肌肉。

l 新手可能无法正确做出动作，也更容易受伤

关于不稳定平面与自由重量训练

在稳定平面进行自由重量训练中加入不稳定器械或者不稳定表面后会使力的产生、发力率和功率输出等指标均降低。稳定平面的自由重量训练可以更好的将专项性、不稳定性结合起来，特别是再针对力量和爆发力进行训练时。传统的稳定平面自由重量训练已经可以提供足够的满足专项适应发展需求的不稳定性，因此没必要在稳定平面自由重量练习中据徐增加不稳定性。———《NACS-CSCS指南》第16章 传统动作的变式训练和非传统器械训练的练习方法

### 固定器械

固定器械主要指大中型的健身器械，包括各种固定架。

固定器械的优点：

l 相比，更安全、容易上手

l 可以快速调整负重

l阻力的方向不是垂直的，为参与动作的所有肌肉群提供足够的阻力

l部分固定器械可以更加孤立的刺激肌肉，这可以增加肌肉激活以增强关节稳定性，并且孤立训练在康复训练中较为有效。

固定器械的缺点：

l 将动作限制在固定平面内

l 主要是单关节运动

l 对运动表现的提升较为有限，有的甚至会降低运动表现

l 对平衡、稳定能力没有提升

l 设计不一定完全适合用户

l 价格昂贵

l占地
