
# 训练前该做的准备

出发前应该先明确当天的训练安排，可以提前把课程导入码表或骑行app，也可以做成纸条，贴在把立上。除非是非常简单的课程，例如3个小时的二区，否则，不建议完全靠大脑来记忆。

如果准备到户外训练，还需要根据课程的内容，选择合适的路线。例如，今天要练习2分钟无氧爆发，可能需要找一段短陡坡；如果是有氧耐力，则应该尽量选择纯平路，避免任何爬坡路线。有的时候，甚至需要根据实际道路情况，修改或调整训练计划，例如拉长热身时间，或者调整间歇的次序等。

此外，出门骑应该检查车辆以及装备的性能，确保可以正常工作，避免出现故障。

当然，还要带齐出门的必须品，例如备胎，修补工具，先进等等。
