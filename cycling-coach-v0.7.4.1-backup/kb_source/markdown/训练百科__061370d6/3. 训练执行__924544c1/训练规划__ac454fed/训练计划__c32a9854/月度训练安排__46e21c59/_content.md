
# 月度训练安排

### 月度训练安排

关于月度安排，实际操作的时候，因为大多数人都是按照“周”来安排生活、工作和学习的，因此，训练通常也是用“周”，而不是“自然月”来安排训练周期。目前常用的两种周期是：
- 3+1
- 2+1

也就是训练三周休息一周（左右），或者训练两周训练一周（左右）。体能高，恢复能力强的运动员，通常使用3+1的安排，否则使用2+1的安排。

只要训练周安排好了，那么无论使用2周还是3周的模型，唯一需要做的就是“负荷递进”，也就是说，这一周的训练负荷要比上一周高一些。具体高多少，要依据运动员的实际能力，身体适应情况。一般的原则是提高5—10%。你可以以训练时长、TSS作为参考数据。Joe Friel最新的《公路车训练圣经中》有一张表格，里面给出了根据训练时长和TSS来分配训练负荷的建议，可以参考。

对于不上班，或者工作/学习时间更为自由的业余车手来说，中周期的训练安排可以更灵活一些，Joe提到了以9天为一“训练周”，这个训练周可以安排三节强度课，同时保证有足够的休息时间，以达到更好的训练效果。

休息周如何安排呢？首先，休息周不是完全不骑车，而是骑一些轻松的内容，从而减轻训练负荷，增加恢复时间，让身体可以准备好接下来2/3周的训练。另外，休息周还可以做的一件事就是测试。例如，FTP每4-6周就可以测试一次，而测试之前有要求恢复2-3天，无疑，休息周是进行FTP测试的最佳时机了。
