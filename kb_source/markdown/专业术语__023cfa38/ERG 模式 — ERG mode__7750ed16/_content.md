
# ERG 模式 — ERG mode

定义： 智能骑行APP（如Zwift）配合智能功率台/功率计，根据课程自动调整阻力，锁定功率目标的功能。可用于限定输出功率，以免骑出过高或过低的功率。

读法： 1：直接读出三个英文字母。2. '鹅儿哥''e:g‘'

说明： ERG是ergometer的缩写，中文称为测力计。通过骑行来进行测试的测力计类似于功率测试台。erg本身也是“做功”的物理单位，将一个达因（dyn）力施加在物力上产生同方向1cm的位移。这是比1牛米、1焦耳更小的单位。
