
# 概述

力量训练已经被证明可以提高自行车手的运动表现。场地车、山地车等项目的运动员都有进行力量训练的传统，公路车手在过去不太愿意做车下力量训练，原因主要有两个：
- 骑行训练时间比较长
- 公路车车手的身材都比较瘦小，特别是上肢和躯干，来到健身房，会比较尴尬

近些年，由于一些教练员和科研人员的研究，以及一些优秀运动员的自我实践，都说明车下的力量训练可以提高公路车手的运动整体表现，以及一些专项表现，例如爬坡、冲刺。当前比较流行的功率训练理论，将功率拆分成踩踏力量和踩踏速度。提高踩踏力量和加快踩踏速度，都可以提高功率，在体重不变的情况下，功体比升高，从而运动表现提升。而力量训练恰好对这两个方面都有帮助。

很多人对力量训练有一个误解和担忧，担心力量训练会让自己变成大块头，体重大幅增加，导致功体比不增反降。其实，力量训练只是一个统称，针对不同的人员有着不同的训练方式和形式。大家印象中，健身房里面的肌肉男（女），主要是在增肌。这可能是受到了欧美文化以及健美运动的影响。对于自行车手，我们要根据自己的需求来进行基础和专项的力量训练，只要练对了，并不会让肌肉量猛增，完全不用担心功体比下降的问题。

还有研究显示，力量训练不仅可以增加力量，也可以增强耐力。慢肌纤维变强之后，乳酸产生的速度也会变慢。此外，力量训练还可以加强骨骼，减缓肌肉功能衰退。

无论你想提高车上运动表现，还是只想把骑车当做一生的运动方式，都应该去做力量训练。

说明：力量训练有多种叫法，例如阻力训练、负重训练、车下训练、肌肉训练、举重训练等，有可能是相同的意思，也有可能指代不同的内容。这主要来自于国外名称的不统一和国内译法的不统一。但是，随着学习，很容易正确理解，所以不用担心。

### 五种力量
- 向心力
- 离心力
- 等长力
- 速度力量：高速运动的力量
- 反应力量
- 启动力量
