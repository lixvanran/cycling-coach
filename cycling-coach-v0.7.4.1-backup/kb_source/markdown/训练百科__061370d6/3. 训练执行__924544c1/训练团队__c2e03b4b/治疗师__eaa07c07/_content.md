
# 治疗师

身体是一个复杂的系统，一套精密的“仪器”，即使平时认真保养，也难免出现问题。治疗师可以帮你解决这些问题。

由于很多问题都是和自行车运动本身相关的，也就是说，问题的发生与从事这项运动的行为、方式有关，比如重复千百万次的踩踏动作，因此，当出现问题时，在描述病情的同时，还应该说明自己从事的运动。最好是找一个有治疗自行车运动员经验的治疗师。

国内目前（2023）主要可以找到医院的运动科、私立的运动康复工作室、针灸、按摩、正骨等中医医院。
