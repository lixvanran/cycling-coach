
# 强化期（Build）

### 强化期（Build）

强化期，按照乔·弗里尔的说法，主要是提高能力三角形的高级能力，可以理解为无氧供能系统为主的强度的能力，包括冲刺能力。从另一个角度去看，基础期的训练内容是让运动员到达比赛终点的能力，强化期训练的内容是让运动员对抗对手、赢得比赛的能力。更严谨地说，是为比赛所需的高级能力做针对性训练。

强化期通常要比基础期短很多，一般只有1-2个月。原因之一就是无氧能力通常反应比较快，但是一旦停止刺激也会迅速下降。

强化期开始进行更多高强度训练，同时还要尽量维持有氧耐力。

强度：70-80%的最大心率。FTP的80%以上。体感上可以说完成整句，但中间需要喘气。

频率：每周3次，配合恢复骑行和休息日。

训量：每次1小时，逐渐增加5-10%左右。

长度：1个月
