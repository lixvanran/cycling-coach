
# 功率时长曲线——Power Duration Curve（PDC）

定义： 基于实际平均最大功率数据估算的可达到和可重复的峰值功率值形成的一条曲线（图中红线）。

应    用： 这是TP/WKO中最重要的功率图表之一。用于计算mFTP，FRC和Pmax。WKO4以后的版本可用。由不同时长的最大功率连接并平滑处理而成的曲线。时间越短，可以输出的最大功率越高。时间越长，可以输出的最大功率越低。
