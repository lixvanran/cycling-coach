
# 概述

截止到创作之时（2023年3月），此章节主要收录的功率数据分析软件。包括国内比较知名的TrainingPeaks App和WKO，以及其他几个专门用于数据分析或包含此功能的软件或平台。

这些软件的基本功能都大同小异，绝大多数也是收费的，费用也都差不多，一个月100多元。但是每个软件/平台的界面不太一样，比较新的界面会更友好一些，也会有一些特色功能。

Goldencheetah和intervals.icu目前不收费，基本功能也是够用的。不过，收费肯定是趋势。所以在选择之时，应该考虑收费，未来更换平台，转移数据等问题。
