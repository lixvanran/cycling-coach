
# 训练区间的意义

### 训练区间的意义

正确使用训练强度区间进行训练，对于训练的有效性非常重要。正确理解训练区间，是正确训练的前提。前面已经讲过如何进行分区，下表可以帮你了解每个训练强度区间的含义。

不同的强度区间对应这不同的骑行能力。你要提高哪种能力，最简单的就是要多骑相应的区间。不过，训练是个复杂的事情，我们可以帮你更好地设计训练课程和计划。
