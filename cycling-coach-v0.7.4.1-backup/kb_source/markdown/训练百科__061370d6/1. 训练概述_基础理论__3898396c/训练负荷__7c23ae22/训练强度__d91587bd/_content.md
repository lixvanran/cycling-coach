
# 训练强度

### 什么是训练强度

训练强度是训练输出的水平高低。对于公路车来说，训练强度就是你（实际骑多快÷最快可以骑多快）。实际骑行的速度越接近你可以骑的最快速度，强度就越高。但是应该知道，这个“最快可以骑多快”，通常是有条件的，比如多长时间，在什么路上，什么样的骑行环境等。因为这些因素都影响你能骑出来的最大速度。在理想环境中，可以实现的最大速度与持续时间成反比，也就是说，要求连续骑行的时间越长，能够骑出来的最大均速就越低。

我们在上面，使用了“速度”作为评判训练强度的一个标准。这也是最古老、最常用、最容易理解的一种强度计量方法。此外，我们还可以用时间（比赛常用）、体感、心率和功率等指标来测量训练强度。

### 主观感知（perceived exertion）

心率计出现之前，人们用主观感受衡量训练强度。这种方法的部分等级标准至今仍然沿用。耐力或“有氧”训练是指长而慢或长而稳的骑行。计时赛的强度、间歇或冲刺则通常需要达到相应时长的最大速度（功率）。见RPE。

优点：

l 叙述性、直觉性。

缺陷：

l 无法确保可信可靠。

l 容易导致训练过度或训练不足。

### 心率训练强度

心率计根据心跳次数来量化训练强度。每个人都有一个最大心率，一般认为不超过220bpm。因此训练时的心率越接近最大心率，说明训练强度越高。而越接近静息心率，强度越低。

这种手段使运动员们免于主观臆测自己的输出，使训练强度的衡量标准化。不同的训练系统，对于训练强度的分区也可能不太相同。

优点：

l 量化，也就是说可以准确地测量输出强度。

缺陷：

l 购买心率计需一定的成本。支持分区计时功能的心率计会更贵，有时还需一台配套的电脑。

l 与心率关联度较差的力量输出和踏频情况常常被忽略。车手们会紧盯着心率，忽视其他方面。

l 在短促的强输出中，心率的上升不够灵敏，无法反映输出强度；特别是当强输出后有比较充分的放松过程。冲刺后，心率会继续升高几秒，而且可能达不到最大心率。

-------

多维心率训练

当指定踏频和速度与心率，训练也可以更加具体。比如以“75%最大心率+50踏频”的方式改善肌力，以“75%最大心率+125踏频”的方式改善踏频情况。

### 功率训练强度

使用功率作为训练强度的标准，是这几年的主要趋势。相对于速度，使用功率作为指标，确实更加直观，受外界干扰更少。

根据功率划分训练强度的思路跟使用速度、时间、心率等是一样的。对于划分强度的标准，主要依据供能系统或乳酸浓度等指标。最常用的就是按照最大摄氧量的百分比以及按照FTP/LTP来划分强度区间。

优势
- 离揭示训练最重要的指标又近了一步。

缺陷：
- 昂贵。
- 复杂。

科学理论的局限

现代生理学测量手段只能让我们对运动本质有一个“大概”的了解。这些手段将不断改进，但别忘记一点：科学理论永远不能百分百代替一套老到的训练计划和一个积极的锻炼心态。
