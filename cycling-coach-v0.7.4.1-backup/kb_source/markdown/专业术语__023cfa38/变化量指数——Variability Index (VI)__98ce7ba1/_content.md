
# 变化量指数——Variability Index (VI)

定    义： 某个训练课程的标准化功率（NP）与平均功率（AP）的比。反映一次骑行的功率波动情况。
单    位： 无
公    式： VI = NP ÷ AP（软件自动计算）
举    例： 这次个人计时赛的VI竟然高达1.4，下次努力保持稳定。
应    用： 当VI=1时，说明骑行非常稳定，体力消耗也大。当VI＞1.05时，说明骑行不够稳定。爬坡多的比赛或山地车比赛的VI通常比较大于1.2。ITT比赛、铁三比赛则追求更小的VI。
