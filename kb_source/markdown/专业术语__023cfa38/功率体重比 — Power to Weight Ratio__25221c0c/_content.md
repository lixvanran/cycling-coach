
# 功率体重比 — Power to Weight Ratio

定义： 骑车人的体重与其在某一时长的输出功率之比，即单位体重可以输出的功率。

缩写/简称： 功体比，P:W

公式： 功率/体重

说明： 功率形态通常使用功体比来对比不同车手之间在某一特定时长下的功率输出能力，例如对比FTP或冲刺的功体比。平路骑行，通常，绝对输出功率为主导，而当爬坡时，功率比可以更好地反应车手输出功率的能力。如果车辆装备的重量差异比较大，考虑综合重量也是有意义的。
