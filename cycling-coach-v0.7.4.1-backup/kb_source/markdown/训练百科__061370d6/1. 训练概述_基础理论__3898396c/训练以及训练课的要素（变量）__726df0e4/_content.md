
# 训练以及训练课的要素（变量）

对于自行车训练计划，包括一次训练课的安排，有且只有以下几个要素可以调整。不同的要素组合，就构成了不同的训练课，也就会产生不同的训练效果。

### 训练的要素
- 剂量：训练课的难度
- 密度：困难训练课的分布情况，或者说频率。
- 训练量：总的训练时长或容量。
- 训练强度：总体/平均训练强度
- 频率：每周训练的次数。
- 地形：不同的地形可以提供不同的训练内容。主要有平路、起伏、短陡坡、长爬坡以及不同的组合。
- 环境：高原vs平原，高温vs低温等

### 训练课的要素
- 强度：整体强度，可以参考IF。
- 时长：整体时长，可以参考TSS。
- 间歇：间歇的强度和时长、次数和组数。间歇休息的强度、时长。
- 踏频：超出舒适踏频会增加难度。
- 环境：室内vs室外等
