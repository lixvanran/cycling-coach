
# 🐧 全职训练/职业发展需谨慎

这几年国内公路自行车竞技变化很大，特别是青少年阶段的竞争异常激烈。国家也在通过各种方式筛选人才，有天赋和之前就在苦练的孩子们已经成了第一批“受益者”。接下来几年，孩子们的竞争会保持相当的激烈程度，也包括各个各个俱乐部和培训机构，以及新生教练们。

奉劝大多数孩子们，不要盲目放弃学业，天天幻想站台、单招考大学。可以先试试有没有天赋，或者将训练的目标定义为提高骑行能力，参加几场青少年比赛，这样都是没问题的，但走职业要慎重。切不可轻易相信一些不负责的教练所做的不切实际的承诺。

同时希望培训体系尽快搭建起来，让孩子们能够接受正确的教育、科学的训练，提供更公平的训练、比赛环境和必要的保护。
