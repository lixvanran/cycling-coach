
# 巅峰期的训练安排以及营养和心理问题

### 

主要采用高于比赛强度的短时间训练。

对于这段时间的训练，运动员的身体应该能够快速适应和恢复。如果间歇训练开始时，感觉倦怠，呼吸心跳没有及时做出反应，说明身体疲劳。另外一种症状就是全力输出后心率和呼吸恢复正常有氧水平的时间超过3-4分钟。这种情况，应该考虑调整训练。

训练后应该多休息，不应有其他过多刺激身体的行为。除了基本休息，仍然推荐慢骑。

适当调整生活，延长睡眠时间，将啤酒留着庆祝，不要尝试新东西。

这段时间，如何维持有氧能力是关键。可能需要加入一些长距离骑行。

### 营养方面

很多人希望减重，增加功率体重比。但这并不是适合的时间。而且，减重会影响训练。应该保证能量支出与摄入的均衡，尽量选择健康绿色的食材。

可以选择好的维生素片+抗氧化剂药物补充身体。注意：大量溶于脂肪的维生素和铁是有毒的。

### 心理问题

调整心态，找一些需要做的事情做，比如检查车辆。适当的担心自己的成绩可以让自己更加注意一些生活和训练细节。

巅峰期可以让你比那些持续训练到比赛前的人提升最高15%的成绩。做好记录，可以作为以后的参考。

达到最佳状态需要考虑的三个要素：性格（personality)、激励因素（Motivational factors）、巅峰状态战略（Peak Performance Strategies）和应对逆境的技巧（Skills for Coping with Adversity）
