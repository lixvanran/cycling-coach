
# 功——Work

### 功——Work

定 义： 如果一个物体受到力的作用，并在力的方向上发生了一段位移，那么这个力对物体做了功。功代表消耗的能量。

单 位： 焦耳 / j

公 式： 功 = 力 × 位移（work =force × distance）

举 例： 1小时骑行做功约500-800kj。以200瓦的功率骑行1小时相当于做了720kJ的功。
