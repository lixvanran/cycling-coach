
# 运动饮料

### 运动饮料

运动饮料是一种为运动员的训练和比赛补充液体同时补充营养的一种专业饮料。这种饮料中通常会加入碳水化合物等能量物质以及出汗会流失的钾、钠等矿物质。按照碳水化合物的含量，通常可以分为三种饮料类型：

a) 等渗（Isotonic）：正常。与人体体液平等，通常含有5-8%碳水化合物，加入钠促进吸收。适合任何时候饮用。例如，佳得乐Gatorade

b) 低渗（Hypotonic）：排空快，碳水化合物和矿物质少，适合热天大量饮用，需要及时补充能量。例如水、非常淡的果汁、一些低热量低脂肪饮料。

c) 高渗（Hypertonic）：排空慢，碳水化合物10%以上，补水慢，适合训练后和碳水化合物以及蛋白质一起补充。例如蛋白质恢复粉，高浓度碳水饮料。

根据实际需求选择不同类型的饮料。

注意：

运动饮料并不适合日常引用，会增加身体代谢的负担，摄入太多能量，或引起其他问题。
