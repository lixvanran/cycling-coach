
# 功能阈值功率——Functional Threshold Power(FTP)

定 义： 车手在准稳定状态，且没有明显疲劳的情况下，1小时左右可以维持的最大功率。

单 位： 瓦 / w

公 式： 最常见的计算方法是：最大20分钟平均功率×0.95 （软件自动计算）

用 法： 使用FTP来划分功率训练强度的区间。

说 明： FTP可以作为标准ITT比赛的重要功率参考指标。更重要的功能是作为设定强度区间的标准。
