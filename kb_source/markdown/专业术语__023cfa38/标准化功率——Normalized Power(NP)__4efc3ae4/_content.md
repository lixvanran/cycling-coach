
# 标准化功率——Normalized Power(NP)

定 义： 估算一段不稳定骑行的实际输出相当于平均功率为多少的稳定骑行。

单 位： 瓦 / w

缩 写： NP

公 式：（软件自动计算）

说 明： 一种算法，用于估算持续时间超过20分钟的练习或努力的生理成本。相对于可以稳定输出的平均功率相同的练习，不稳定的练习更加困难，因此，功率在FTP以上的部分的权重大于功率在FTP以下的部分。

举 例： 妙峰山上下的平均功率只有230w，但是NP却有300w。

别 称： 常态化功率、归一化功率
