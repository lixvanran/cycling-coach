
# 训练需要收集哪些数据

如果你准备与教练合作，那么让教练员了解你是非常重要的。教练也会主动收集各种信息，主要包括：

### 1. 基本信息
- 姓名
- 性别：女性需要考虑的因素更多一些。
- 年龄：青少年和老年的训练要与青壮年和中年人有所区别。
- 身高
- 体重
- 常住地：这与他的训练环境有关。
- 邮箱：注册TP账户和问题沟通使用
- 手机号
- 所属俱乐部/车队：客户可能有自己的车队

### 2. 身体状况
- 身体状态：是否有体态、灵活、柔韧等问题。
- 骑行感受：骑行过程中，身体是否出现过疼痛、不适
- 有否疾病：一些疾病和损伤可能不适合做剧烈运动，例如心脏病、高血压。
- 家族病史：有家族遗传病史的也要注意
- 是否受过伤：比较大的伤，动过手术的，造成身体结构改变，目前影响运动的。

### 3. 器材情况
- 当前使用的车辆
- 其他可以使用的器材和装备，例如功率计、骑行台
- 是否做过fitting：车子是不是合适。如果没做过，车子也明显不合适，或者出现典型的骑行不适，应该先进行fitting。

### 4. 训练历史
- 是否参加过其他运动：不同的项目让身体产生不同的变化。比如练过短跑，大腿通常比较粗，爆发力比较好。
- 自行车运动年龄：骑龄可以反应客户的大体骑行能力，包括骑行知识水平。如果是以竞技为训练目的的，那么之前参加过的比赛的类型，成绩都是需要了解的。
- 骑行风格：骑行风格非常重要，一直休闲骑和经常骑长途的基础是不一样的。参加比赛，经常登台与完赛也相差甚远。
- 历史骑行/训练的频率和时长：了解之前的骑行训练规律、习惯，来评估如何安排新的训练

### 5. 训练条件
- 周围的骑行环境：有没有合适的骑行路线。市区内可能不安全。
- 当地天气环境：如果经常下雨，那么室内训练的比例就要增加。
- 室内骑行环境：室内应该布置得当，保证通风和温度等。

### 6. 训练目标——有针对性地安排训练
- 总体目标
- 详细目标

根据这些目标，来找到对应的区间，来安排具体的训练课程。

### 7. 训练可用时间

通过了解客户可以用于训练的时间来安排不同的训练课程。
- 工作日每周可以训练几天
- 每天分别可以训练几个小时
- 每天的可训练时间是连续的还是分成几段的
- 周末每天分别可以训练几个小时
- 每周需要几天休息
- 有没有一些规律性的时间，比如周期性出差、加班

### 8. 运动水平和骑行表现

之前的骑行表现，对于确定如何开始训练也非常重要。
- 新手还是老手
- 体能水平
- 个人优势与不足
- 之前的测试/比赛成绩
