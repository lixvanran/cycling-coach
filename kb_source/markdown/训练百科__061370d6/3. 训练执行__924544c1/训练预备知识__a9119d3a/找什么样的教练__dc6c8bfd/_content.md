
# 找什么样的教练

### 首先要看资质：

目前业余圈的专业教练不多。国家这两年（2025年内）逐渐面向大众开放了公路车教练员培训和资格考试。但是有一定门槛，因此完成学习的人数并不多了，而且级别较低。

也有一些退役的老教练，目前也在做教练员工作。

业余圈内还有一些教练，参加过国外的教练员资格证或培训。

此外俱乐部里也会有一些“无证”的专业教练。可能是原职业队员或一些喜欢研究训练的业余高手。他们通常也是非常棒的选择。

### 其次，知识水平

教练是一个需要多重知识的职业。除了训练学，还包括生理学、营养学、力学、心理学、教育学、管理学等多方面的知识。虽然目前国内，特别是业余圈很难找到全部都非常厉害的全能教练，但是这名教练应该至少学习过相关知识。

### 最后，也是最重要的一点，执教经验

理论是基础，执教经验能确实帮运动员解决具体问题。经验越丰富，一般来说越能更快低引领运动员进步，少走弯路，特别是在个性化指导方面

当然，不同的教练，因为知识领域、执教经历等的差异，可能针对某一个特定人群更加有经验，例如TT车手，女性车手，中老年车手等。

目前国内的大多数教练还处在学习实践的过程中，还需要更多的学员和机会来提高。大家在选择教练员的时候，也需要根据自己的实际需求来选择适合自己的教练。
