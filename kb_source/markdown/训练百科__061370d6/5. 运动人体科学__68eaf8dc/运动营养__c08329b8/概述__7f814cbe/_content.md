
# 概述

### 概述

人活着需要能量，能量的来源就是大自然的食物。运动提高了对能量的要求。而且，不同的人，不同的运动项目等因素对能量的要求也不同。

公路自行车，作为一项耐力运动，多年来的运动营养研究告诉人们，主要需要以碳水化合物为主要能源。近些年，对脂肪的看法发生了一些变化，开始强调脂肪供能对于运动表现的重要作用。

不过，整体研究结论大体就是这样，更关键的是如何来摄入这些营养。吃什么、吃多少、如何吃成为了运动员更关心的问题，主要原因还是个体以及需求的差异。

目前对于运动营养方面的研究还比较有限，更有趣的是，一些前沿专家和顶级车队反而提出回归天然食物，似乎与一些科技产品唱反调。

其实，运动营养和训练一样，有一些基础通用的理论，但是个体差异也非常巨大。寻找最适合自己的食物和饮食习惯，和训练一样，是一项长期的工作。
