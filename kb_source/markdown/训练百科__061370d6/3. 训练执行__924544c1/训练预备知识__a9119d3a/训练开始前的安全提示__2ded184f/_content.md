
# 训练开始前的安全提示

训练是一项艰苦的工作，同时具有一定的危险性。因此训练时应该注意自己的身体状况。身体发出任何异常信号（头疼、头晕、心跳加快或过慢、心率不齐、呼吸急促、喘不过气，不想运动，心烦易怒等）都要及时停止训练并休息，反馈给教练，必要时立即就医或求助。

在实际道路上骑行，首先应该确保自身安全。切不可为了训练违反交规，如任意闯红灯，甚至跟机动车飙车。即使是要求稳定骑行的有氧训练，遇到红灯停下来等一会也并不影响训练效果。

切记！公共道路不是比赛场地！
