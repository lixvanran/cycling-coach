
# 基础期（Base）

### 基础期（Base）

基础期，顾名思义，就是打基础的阶段。基础期也标志着训练年正式开始。对于公路自行车运动，基础体能主要是指有氧能力（这里泛指以有氧系统为主要供能系统的相应运动强度的能力，而不是指最大摄氧量）。根据1.6 骑行训练能力三角形Training Triad，基础期就是要加强速度能力、有氧耐力和踩踏力量。

按照线性周末的原则，基础期的训练也呈现渐强模式。踩踏作为骑车的基础和核心，是首先要完善的。力量训练作为两个功率组成元素（力量和踏频）中变化范围更大的一个，也需要花很多的时间去锻炼。高强度训练对于力量的要求很高，而基础期的强度不高，所以通常会通过车下力量训练和低踏频爬坡等方式来提高并维持踩踏力量。

随着体能的增加，骑行的时长和强度也逐渐增加，强度提高到3-4区，2区的时间也拉长到3-4个小时，因此车下力量训练也需要减少。

基础期的时长通常是最长的，一次可达2个月以上。原因之一，就是基础能力对训练的反馈比较慢，需要较长时间的积累。坚实的基础对于之后进行更高强度的训练内容也至关重要。停训后基础体能下降速度也比较慢。

强度：主要强度低于70%的最大心率，FTP强度的55-75%。体感上可以轻松对话，不会喘粗气。

频率：每周4-6次

训量：每周6-15小时，逐渐增加。

长度：2个月左右
