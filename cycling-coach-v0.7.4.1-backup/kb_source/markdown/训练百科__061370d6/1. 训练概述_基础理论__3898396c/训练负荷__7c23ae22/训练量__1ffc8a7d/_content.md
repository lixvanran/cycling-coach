
# 训练量

训练量是训练负荷中最容易量化的元素之一，用于说明训练的多少。训练量根据实际需要，可以采用不同的计量单位，最常见的训练量统计单位是：
- 训练小时数：每周的训练小时数。
- 训练频次：每周训练几次

训练量的大小是车手训练安排规划和进度监控的重要指标之一。

周训练时长：
- 职业车手的周训练时长可达20-30个小时，甚至更长。
- 业余精英车手的训练量通常不逊于职业车手。
- 平常上班、上学的业余车手来说，每周10个小时左右的训练量比较常见。
- 有些业余车手每周只能训练6-8个小时，也能达到非常高的水平。
- 如果周训练时长小于6小时，训练安排和执行可能都有困难。

周训练频率：

训练次数也很重要。
- 职业车手每周训练5-6天，每天1-2次
- 业余精英车手每周训练4-7天。
- 推荐每周保证3-5次的训练，可以达到比较好的训练效果
- 如果只有周末可以骑行训练，周中也几乎无法进行有效的辅助训练，则不推荐训练。

训练量和训练强度，在训练规划过程中要达到一定的平衡，同时又要有侧重点。简单来说，训练强度越高，训练时长就越短。随着能力的提升，高强度训练的持续时间，有氧能力以及身体的恢复能力都会提升，总的训练负荷就可以提高。
