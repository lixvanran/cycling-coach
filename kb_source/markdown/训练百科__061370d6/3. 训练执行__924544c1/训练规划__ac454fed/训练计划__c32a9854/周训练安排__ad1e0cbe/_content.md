
# 周训练安排

### 周训练安排

训练周是最小的训练周期。安排一周的训练并不算困难，需要先知道下面几条基本原则：
- 一周内可以安排1-3个主要训练内容
- 一周内通常需要安排1-2个休息日。可以完全休息或骑行骑行。
- 剩下的时间主要安排次要训练内容
- 最难的训练课安排在身体最轻松的日子，通常是在休息后

知道这几个基本原则后，还需要知道运动员的实际情况。大多数业余运动员，最长的可用训练时间都是在周末。有些人两天都可以训练，也有一些人还要拿出一天来陪家人。因此通常周五和周一都是需要轻松安排的。周一是休息日，似乎成了惯例，因为周末两天的训练量通常比较大。因此，通常周二会安排强度最高的训练课。周三和周四次之。需要注意的是，如果连续训练三天，一般业余运动员可能会休息不过来。因此，周三到周五的训练需要稍微动动脑筋。当然，如果每周只有三天可以训练，那么基本上每次训练都是重点了。
