
# 室内训练房的布置建议
- 保证通风条件，推荐两个以上的风扇
- 保持舒适的室温，推荐20℃左右
- 保证地面平稳
- 准备好毛巾用于擦汗，保护车辆不被汗水浸湿
- 准备好充足的水和食物，并放在触手可及的地方
- 推荐面对窗户，可以观察不同的景色，或者播放视频
- 铺好地垫，可以降低噪音，防止汗水浸泡地板
