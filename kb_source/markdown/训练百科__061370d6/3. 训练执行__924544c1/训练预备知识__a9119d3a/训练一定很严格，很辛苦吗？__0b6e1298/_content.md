
# 训练一定很严格，很辛苦吗？

正式的训练通常不会很轻松。感觉轻松可能也是相对于更高强度的训练而言。不过，对于新手来说，特别是业余车手，一开始的训练不会特别辛苦，因为刚开始主要还是培训训练习惯和技术动作。

此外，如果你的竞技目标不高，可能只是提高ftp或者健身，那么训练的整体强度也会低很多，而且相对更加灵活。

如果你的竞技目标比较高，但确因工作或学习导致无法保证规律训练，这时就需要与教练的深度配合，及时沟通，随时调整训练安排。
