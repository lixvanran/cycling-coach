
# 🤠 为什么看了那么多训练视频还是不知道怎么练？

原因其实很简单。

因为训练和学习一样，是一个从基础到高级，从简单到复杂（再到简单）的过程。就好像我们学语文，先学拼音，再学汉字，词-句-文。中间的每一步都需要沉淀、积累、实践。而训练视频，特别是短视频，只是把整个学习中一些点拿出来，用很简单的语言讲。这些知识点支离破碎，而且讲述着很少告诉你这些知识点是来自一年级语文课本，还是来自大二文学赏析的课本。

提出这个问题的人，通常也是训练小白，那自然越看越糊涂。今天骑了一个“小学生”的课太简单了，明天又看了一个“研究生的课题”觉得挺有意思，试了试发现搞不定。这样一来二去，耽误了时间，发现没有明显进步，没准还在过程中受了伤。

如果想要自学训练，再视频的海洋中探索之前，建议至少先认真阅读至少一本关于训练的书籍，例如中的《公路车宝典》。这样在海里遨游时，才能认出各种鱼类和其他生物，知道哪些鱼是你可以抓的，哪些鱼是目前需要避开的（鲨鱼）。
