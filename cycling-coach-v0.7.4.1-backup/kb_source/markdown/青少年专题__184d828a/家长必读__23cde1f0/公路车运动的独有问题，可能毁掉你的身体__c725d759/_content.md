
# 公路车运动的独有问题，可能毁掉你的身体

公路车运动属于耐力运动，这意味着需要长时间保持一个姿势骑行。骑行的姿势+器材的特殊性+长时间，使得这项运动可能导致骑车人经历一种在其他运动项目中罕见的的经历——会阴压迫。

会阴压迫的直接感受就是难受坐在车座在不舒服，无法保持发力姿势。长时间或严重压迫还可能造成生殖器的生殖泌尿功能出现障碍，例如：
- 勃起障碍
- 前列腺炎
- 尿道炎
- 尿急
- 漏尿

造成问题的原因很简单，就是这一区域的血管和神经受到压迫。造成压迫的原因则各有不同。常见的问题包括：
- 身体结构异常，例如骨盆侧倾
- 车辆设定不合适。车座太高最为常见。
- 车座不合适。包括材质、外形、宽度等方面
- 骑行姿势长时间不变。
- 身体力量不平衡、薄弱
- 长时间大力坐踩
- 长时间骑行

一般来说，解决方法也很简单：
- 调整自行车设定，可以进行BikeFitting
- 选择适合的车座，一定要坐上去试试
- 经常变换骑行姿势
- 加强身体训练

如果骑行过程中出现相关症状，应该及时停止骑行，寻求专业建议。如果已经造成问题，一定要及时就医。

说给家长的话：

青少年的恢复能力快，有可能睡一晚就没事了。特别是这个部位，很多人不好意思说，因此也建议家长主动沟通，并做好相关知识的教育工作。
