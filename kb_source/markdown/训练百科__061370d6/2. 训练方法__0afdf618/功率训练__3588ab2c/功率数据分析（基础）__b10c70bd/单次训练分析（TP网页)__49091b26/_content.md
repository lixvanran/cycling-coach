
# 单次训练分析（TP网页)

### 查看课程完成度

当运动员完成了一次训练，将数据上传到TrainingPeaks(TP)。我们首先直观地会看到这次训练课的完成情况。TP通过颜色来告诉我们答案。

![image_tGzoRboc2h.png](attachments/93725dce-5af3-4490-b678-621e10567a6e.png)
- 绿色表示训练课程基本完成，完成度为80-120%
- 黄色表示训练课程完成的不好，完成度为50-80%或120-150%。
- 橘色表示训练课基本没完成或超量完成，完成度为<50%或>150%。
- 红色表示训练课没有执行，完成度为0%
- 灰色表示此次训练不在计划之内，或者训练课没有规定具体的完成指标。

### 查看完成详情

点开本次训练课，我们可以看到具体的执行情况。

![image_V5-ZjYEa-x.png](attachments/e710e259-a148-4f84-a222-6800ac806134.png)
- 粉色线：功率
- 红色线：心率
- 黄色线：踏频
- 蓝色底：计划安排

（不同软件使用的颜色可能会有不同）。

如果粉色的功率线与蓝色吻合，说明训练是按照我们的设计进行的。如果功率过高、过低，或者维持的时间过短或过长，都不符合我们的课程设计。

如果运动员每次都以高于设计要求的功率执行训练，那是否是我们的课程太简单了。相反，如果运动员经常无法完成我们设计的时长，就不得不休息一下，也许我们的课程太难了。

还要关注心率、踏频是不是符合要求或满足预期也很重要。具体目标取决于课程设计的目标和方式。

此外，还可以查看气温、海拔、速度等数据。
