
# 爬坡课程

### 1. 爬坡加速

课程作用： 提高1-2分钟连续起伏路的功率。

课程内容： 在起伏路上，保持稳定的节奏。在距离坡顶还有200-300米的时候，保持坐姿并开始通过提高踏频加速。距离坡顶最后10s左右，增加档位，提高速度。通过坡顶后轻松踩踏，恢复5分钟。

课程晋级：

初级：4次

中级：2×4次，组间10分钟。

高级：2×6次，组间10分钟。

### 2. Over-Under

课程作用：提高阈值输出的耐久性和应变能力。

课程内容：找一段6分钟左右的爬坡。前2分钟先以略低的稳定输出爬坡（约86-90%FTP/92-94%LTHR）。接下来1分钟加速到阈值输出。然后重复1次。

课程晋级：

初级：3×6m，组间6分钟。

晋级：3×9m，组间5分钟。（需要9分钟的上坡）

### 3. 爬坡冲刺

课程作用：提高进攻短陡坡的能力。

课程内容：找一段之前有平路的短陡坡。中等速度 （25-35kmh）骑行，到距离坡底20-50m的位置时，手握下把，开始摇车冲刺。上坡后继续冲刺10秒。掉头休息5分钟。

课程晋级：

初级：4次

中级：2×3次，组间10分钟

高级：2×5次，4分钟休息，组间8分钟。

提示：如果摇车时身体上下跳动，升一档。如果车辆左右过度摇摆，降一档。

### 4. 短坡力量

课程作用：提高短爬坡的功率。

课程内容：
- 热身。
- 找一段坡度在6-9%的上坡。
- 7×2m加速，让心率高于阈值心率5-10下。平均功率大约在110-120%FTP。每30s，站起来摇车10下。组间休息4分钟。
- 冷身。

### 5. 长坡力量

课程作用：提高长爬坡的功率。

课程内容：
- 热身。
- 找一段坡度在6-8%的上坡。
- 3×10m@FTP。每2分钟进攻10-15秒。组间恢复10分钟。
- 冷身。
