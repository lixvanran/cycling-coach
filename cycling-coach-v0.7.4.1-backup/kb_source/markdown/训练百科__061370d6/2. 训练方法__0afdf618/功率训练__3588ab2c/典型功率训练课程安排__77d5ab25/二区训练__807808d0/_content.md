
# 二区训练

### 二区训练

一区和二区训练在生理学上没有显著区别。一二区训练是最重要的训练强度，因为一二区训练的关注对象主要是线粒体。一二区训练线粒体的主要功能包括脂肪代谢能力和乳酸清除能力。代谢更多的脂肪则节省糖原，且减少乳酸的产生。增加线粒体清楚乳酸的能力则允许身体可以处理更多的乳酸。

常见的误区：有些人认为一二区（尤其是一区）是"垃圾时间"。这是非常不正确的。训练是否有意义取决于你的目标和执行之间的吻合，同时要考虑是否尽可能的利用了时间和精力。"垃圾时间"最典型的情况是执行偏离目标：如果今天的计划是3小时的轻松有氧骑行，然后运动员却基本一直保持在3区，这样的训练才是垃圾时间，因为3区和一二区之间有生理学意义的区别（能量使用前者更多使用糖原而后者主要使用脂肪）。或者我今天计划是骑无氧但是因为前一天没睡好心率和功率都上不去腿就已经酸了，在这种情况下强行、低质量完成间歇，这样的训练也是垃圾时间，因为你并没有很好的训练到目标无氧区间。
