
# 概述

数据分析是训练的重要组成部分。除非你从来不看数据，完全凭感觉训练，否则，就一定要进行数据分析。哪怕只是掐一下秒表。

功率训练让公路车训练变得更加精细化、个性化。每一秒骑行都产生若干个数据。也因此对于数据分析的要求也比以往更高。而且有TSS、IF、NP、VI等更多指标，学习这些指标是什么意思，就已经让有些人头疼了。

Trainingpeaks APP、WKO或其他功率数据分析软件，已经帮我们把数据进行了归类、整理，并以各种图表的形式展现出现。因此，我们只需要找到我们需要的图表，就可以进行最基础的数据分析与跟踪工作了。

本部分的内容主要以TrainingPeaks和WKO5为示例进行说明。其他APP的数据表现形式可能不同，但根本上都大同小异，因为数据源是相同的。只要了解同一/近似指标在不同APP里面的叫法，就可以快速上手。
