
# 训练日记

训练日记是训练的重要组成部分，是运动员与教练员沟通的重要资料，更是运动员自己的宝贵财富。坚持记录的内容，可以帮运动员找到训练的规律和问题，从而有效改善训练安排。

训练日记并不是简单的训练流水账，而应该侧重于主观感受。如今的骑行码表、APP，可以记录各种信息，包括日期、时间、气温、以及各种骑行数据，并通过各种形式展示出来。作为训练的核心，人的感受是这些仪器装备无法得知的。认真写下训练的感受，课程是不是太轻松或太难，低踏频爬坡能不能坚持，弯道敢不敢切过，这些重要的身体感受可以帮助运动员/教练员了解训练安排是否适当。

此外，一些高科技设备还无法检测的信息，也不要忘记，喝水的量，吃胶的数，身体的不适等等 。

训练内容不一定面面俱到，特别是电子设备可能已经自动记录了很多信息。要选择重要的数据记录。

如果是训练新手，最开始可以多记录一些内容，随着训练逐渐形成规律，则可以不在记录那些已经非常规律或熟知的事情。

### 训练日记中应该详细记录以下内容：

码表里面记录的数据，虽然很全 ，但是并不能直观反映训练过程中的个人感受以及一些特殊情况，所以还需要训练者在日记中详细写清楚一些具体的身体感受，例如：
- 刚开始热身，已经能感受到肌肉酸痛
- 间歇训练，从第几组开始，心脏难受、呼吸困难、肌肉开始酸痛/酸痛无法消除
- 间歇训练，感觉休息时间太长/太短
- 间歇时长/组数/功率目标还可以增加/需要缩减
- 什么时候开始感觉饥饿
- 冲刺使用了什么齿比档位
- 感觉是否全力

此外，当天发生的一些可能影响训练的事情，也应该写进日记，例如：
- 下面提到的睡眠情况
- 白天上班/上学时收到批评
- 跟人吵架
- 吃了平时很少吃的食物
- 身体有一些不影响骑车但会产生一些疼痛不适的问题（例如牙疼）
- 更换了骑行服/车座等装备

### 休息日的日记写什么

休息日也要写日记，主要记录休息日做了什么，自己休息的效果如何。

一般来说，休息日应该避免重体力劳动，特别紧致平时不做的激烈运动项目，例如足篮球、网球等，减少不必要的疲劳，避免意外受伤。

休息日可以增加微量元素和水的摄入，增加柔韧度，拉伸等练习的次数。如果采用了按摩、针灸等其他放松手段，也可以记录跟踪。

这些内容也应该写在日记里。

此外，早晚评估身体的恢复的程度，可以通过评分，hrv、提高等手段进行评价。休息日有效时长，延伸到第二天早晨，综合对比身体恢复情况。

### 睡眠记录

除了晨脉，睡眠是重要训练辅助信息，对于判断身体恢复状态，非常有用。

### 睡眠日记写什么

评价睡眠：
- 睡眠质量（0-10分）
- 做梦情况（是否做梦、1个还是多个，是否还能清晰记得）
- 中途是否醒来（如果是，发生了什么）
- 醒来身体状态（酸痛，还是无感）（0-10分）
- 醒来的精神状态（0-10分）

可以做成模版，每天粘在日记里面。

### 一些可能影响训练的事情：
- 骑得太累，晚上睡不好
- 失眠
- 临时有其他安排
- 前一天力量训练
