
# 对于训练的常见误区

### 常见误区

当问到“你是否想找个教练时？”，给出否定答案的人通常有两种理由：
- 觉得自己水平不够，还不需要教练。
- 知道刚开始骑车，只要骑就能提高，所以也不需要教练，等到无法提高了再跟教练合作。

这两种理由都有一定的道理。比如回答第一种理由的人，把训练看成是一种严肃、正规的事情，认为一旦有了教练，就像上学、上班那样，要每天非常严格地执行训练课程。

给出第二种理由的人，可能是通过某些途径了解到训练初期的这个现象，认为这个阶段请教练是在浪费金钱。

不过，持有以上两种观点的人，其实都忽视了一个根本的问题。那就是训练初期，打好基础的重要性。有人可能会说，基础不就是多骑，不就是2区吗？其实不然，相对于难美类项目，以及一些技巧要求较高的强度，例如乒乓球，公路自行车运动的技术动作相对单一。但是，单一不意味着简单。而且正式因为单一的技术要求，决定着以后所有的运动表现。

好比说，乒乓球运动，你可能弧圈球不好，但是正手快攻很厉害，可以以快制转；反手推挡不好，但是可以用正手侧身位来回击。但是公路自行车的单一技术动作让你别无所选。

更重要的是，训练初期，教练员可以帮你养成正确的训练习惯，传授正确的训练理念，特别对于年轻车手，早期养成训练习惯（训练不仅仅是骑车），对于长期发展是非常有好处的。如果自己已经训练了4-5年，遇到瓶颈再来找教练帮忙，教练和运动员很可能就要一起花很长的时间来纠正、改变固有的训练方式和方法。

很多人一听到训练，就认为需要天天练，而且会非常痛苦，而自己正在上学，所以没法进行训练。训练对于学生来说，并不会要求你按照专业运动员的安排进行训练，而是按照你现有的可以训练的时间来安排课程，提高训练效率。换句话说，就是让你每次的骑行变成一次有效的训练。也就是说只要你骑车就可以训练。

训练并非每次都要非常痛苦，非常累，及时是职业车手的训练，也不是这样的。训练通常是强度与轻松骑混合在一起的。轻松的时候足够轻松，强度课才能突破身体的上限。但这个上限不是终极极限（至少大多数情况都不是），而是一个超出正常能力范围的，身体仍然可以接受的强度。换句话说，训练绝不是每次“累的要死”，更不能出现不应该出现的疼痛、痛苦。

病愈后切记马上上强度。通常我们所说的病愈只是症状的消失，而身体通常还在做深度修复，而且由于几天停训，机能也有所下降。因此，症状刚刚消失，最好再休息1-2天，从低强度、短时长的训练开始，逐渐加强，同时注意身体感受。如果是基于FTP的训练，甚至可以临时将FTP调低5-10w来安排恢复训练。
