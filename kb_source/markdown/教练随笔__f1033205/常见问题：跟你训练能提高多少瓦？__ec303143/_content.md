
# 🛥️ 常见问题：跟你训练能提高多少瓦？

这是很多训练新手在找教练的时候最关心的一个话题。但是这个问题很难有一个准确的答案，因为训练非常复杂，而训练的主体，训练者的情况，例如天赋、训练时间、训练环境、身体基础等都会影响这个问题的答案。

不过，根据多年的执教经验，可以提供一些参考数据。对于15－18岁年龄段：
- 普通学生：走读上学族，训练时间有限，周末可以多骑一点。一般可以练到3.5－4.5w。
- 运动达人：周中训练时间多一些，训练更加规律、认真。一般可以练到4.3-4.8w。
- 训练达人：运动训练时间明显多于一般学生，且对骑行非常专注。一般可以练到4.5-5.2w
- 职业骑行：不是只体校和专业队的队员。准备走职业的学生，拥有充分的训练时间和条件。对训练痴迷，还可以学习相关知识。一般可以练到5－6w。
- 罕见人才：天赋条件都优秀且自己努力、科学训练。一般可以练到5.5－6.5w。

这只是针对本文撰写时，根据个人经验整理的数据，不具有权威性，可以供准备训练的业余车手参与。你的投入与回报成正比。训练环境也有重大影响。如果无法投入足够的时间和精力（无论任何原因）不要跟那些一周15－30小时的车手比较。每周8－12小时的训练时间，只要认真对待，足以让大多数孩子享受运动的乐趣，也可以参加一些比赛，体验那份刺激。

这几年青少年公路车训练竞技火热，但是也希望孩子们以及家长们理性看待。运动骑行与专业竞技是两件事。我们希望培养出更多的优秀运动员，但我们也不希望看到一些不具备条件的孩子因此耽误学习。
