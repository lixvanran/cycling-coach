
# 概述

训练规划是训练中的重要组成部分，为之后的训练提供了指导方向，让训练不再无章可循。然而这一步骤的工作却被很多业余车手所忽略，原因就是第一次做规划会感觉有些复杂，或者发现“计划总是赶不上变化”。

第一种情况，相对比较容易解决，只需要一点点耐心，或者聘请一名可以帮助做规划的人，例如教练员，就可以帮你完成。如果这份赛季规划非常适合你，那么下一年，你就可以参考它来完成，工作量会大幅下降。

第二种情况，可能是由于各种原因，无法保证规律的训练，这时可能需要一份更加灵活的训练计划，来匹配特殊的训练方式。这说起来简单，但是执行起来，确实会更加困难，因为增加了很多变量，需要考虑的因素也就更多。

训练规划对于赛季取得成功非常重要，因此，如何规划赛季，也就成为了车手的一门必修课。
