
# 一次训练需要多少时间

一次“完成”的训练通常包括多个阶段：
- 切换阶段：结束其他工作，换衣服、准备训练装备、准备水和补给品——10-15分钟
- 准备阶段：确认训练内容、开码表、连接设备、校准功率计、GPS定位——3-5分钟
- 热身阶段：正式训练前的热身部分——10-30分钟
- 训练阶段：训练课的主要内容——30-300分钟
- 冷身阶段：正式训练后的恢复部分——10-30分钟
- 收尾阶段：传数据、换衣服、拉伸——10-15分钟
- 切换阶段：洗澡、换回普通衣服、收拾车辆、洗衣服——10-60分钟
- 因此，给训练留出充足的训练时间。
