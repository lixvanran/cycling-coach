
# 蛋白质

### 蛋白质

蛋白质的主要作用是提供氨基酸，修护身体组织。人体需要二十多种不同的氨基酸，其中八种是必要氨基酸，需要从食物中摄入。推荐每餐获得8种氨基酸，例如米饭和豆类。要保证每1-2天内获得所有8种。蛋白质还可以保持红血球细胞，帮助产生关键的酶和荷尔蒙，控制细胞中的水。

蛋白质并不是很好的能量源，当碳水化合物和脂肪不足时，才充当能量，同时消耗肌肉。坐办公室的人需要每公斤体重0.8g以上的蛋白质。运动员应该高于这个值，比例，在15-20%。

多余的蛋白质会随尿液排除，增加肾脏压力。如果摄入了过多的蛋白质，需要多喝水。如果未能及时补充碳水化合物，会加快蛋白质的分解，因此训练后要及时补充大量碳水化合物（75%），建议1.7-2.2g蛋白质/每公斤体重。

蛋白质对能量的贡献很少（5-15%）。日常需求量是1.2-1.7克/公斤体重。通常在摄入热量食物中就已经含有足够的蛋白质。

推荐食物配比中蛋白质占12-15%。

鸡蛋、肉、坚果、奶制品中富含蛋白质。素食主义者应该从谷物、坚果、豆类中获取足够的蛋白质。

训练后应尽快摄入0.2-0.3g/kg体重的蛋白质已经充足的碳水化合物辅助恢复。碳水的存在会辅助蛋白质修复肌肉。植物蛋白对于练后恢复可能是不错的选择。
