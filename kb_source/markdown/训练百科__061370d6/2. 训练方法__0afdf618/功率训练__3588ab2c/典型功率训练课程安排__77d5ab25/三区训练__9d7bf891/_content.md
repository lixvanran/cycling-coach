
# 三区训练

### 三区训练

三区主要提高肌耐力。

三区强度虽然高于二区，但仍然低于FTP，因此应该可以连续骑行很长时间。训练时，也可以努力长时间保持三区。对于新手，单次间歇也不要太短，推荐15分钟以上。耐力好的车手，可以保持2-3个小时的三区，甚至更长。

一边说三区是比赛大团的速度，但其实比赛中的大团速度变化要比稳定三区难得多。因此，当肌耐力足够稳定之后，也可以通过参考标准化功率——Normalized Power(NP)来提高三区的能力。
