## 7. 风险与不做项

### 风险

| 风险 | 影响 | 缓解 |
|------|------|------|
| HTML5 DnD Safari 兼容 | B1-1 拖拽可能失效 | Fallback: 卡片"+"按钮弹模态框 |
| AI 输出 JSON 不稳定 | B1-2 按钮不出现 | 强 prompt + 前端 try/catch 容错 |
| Phases 应用端点复杂度 | B1-3 排错耗时 | 先 mock 数据验证 UI, 后端分步实现 |
| 视觉换皮回归 | B3 可能改坏现有页面 | 灰度: 先 B3-1 theme, 验证 5 个页面后再批量改 |

### 明确不做

- ❌ 移动端单独优化 (V0.9.x 评估, 当前 web 自适应够用)
- ❌ Premium Paywall (永远不做)
- ❌ 教练侧 / 多人协作 (不在产品方向)
- ❌ Recurring Workouts (放 V0.8.4)
- ❌ Layout 自定义 / Cmd+K Action (放 V0.8.4)
- ❌ StackUp (永远不做, 单人项目)
- ❌ 重写设计系统 (B3 只换 token, 不重写组件架构)
- ❌ 改后端 service / models / database (只调前端 + 1 个 Phases 端点)
