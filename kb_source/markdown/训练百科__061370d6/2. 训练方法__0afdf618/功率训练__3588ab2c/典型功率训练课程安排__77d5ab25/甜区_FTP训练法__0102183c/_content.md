
# 甜区/FTP训练法

### 甜区/FTP训练法
- 甜区和FTP训练的主要目标是提高FTP。训练提高的一般原则是提高功率和延长持续时间。作为甜区训练，提高功率的空间很小（88-93），因为主要是延长时间。FTP课程则可以逐渐提高目标功率，接近5区。
- 甜区和4区训练的关键还是时长，单次间歇推荐不少于10分钟，总体时间逐渐拉长的TTE之上。甜区的间歇长度，通常可以比4区间歇更长。
- FTP训练，还是会有明显的乳酸堆积，因此会非常痛苦。甜区降低了乳酸的困扰，也能达到提高FTP的作用，同时可以提高肌耐力。
- 随着FTP的提高，注意及时提高甜区的区间。

间歇时长安排举例：

SST目标时长：1小时

4*15min（5min）→3*20min（5min）→2*30min（5min）

或者休息时间从五分钟缩短。

甜区 np ＞10分钟，累计骑行
