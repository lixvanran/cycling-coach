
# 如何使用功率骑行台

目前的功率骑行台，使用非常简单，正确装上自行车后，只要再链接骑行APP，就可以使用了。

各个品牌都提供了详细的使用说明：
- 迈金T300的使用手册：http://static.magene.cn/manual/T300_User_Manual_CH.pdf
- 佳明NEO 2T的使用手册：https://download.garmin.com/cn/download/manuals/NEO_2T_Smart_CN_OM.pdf
- 智骑骑行台安装说明：https://space.bilibili.com/29168443/channel/series
- Wahoo Kicker 安装说明：https://www.wahoofitness.com/media/downloads/Wahoo_KICKR22_QSG_5x8_Rev2_Rd10_WithTrans.pdf
