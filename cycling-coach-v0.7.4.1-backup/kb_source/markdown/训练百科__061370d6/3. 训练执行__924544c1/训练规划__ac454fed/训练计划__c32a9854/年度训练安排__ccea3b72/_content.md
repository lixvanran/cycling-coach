
# 年度训练安排

### 年度训练安排

年度训练可以看做是一个最大的周期，月度训练相当于一个中周期，而一周的训练是最小的周期单位。年度训练就是由几十个小周期组成的。

一般来说，年度训练是以比赛为中心进行安排的。而比赛主要分布在夏季，并分别想春秋延伸。深秋赛季结束。因此，年度训练也是这样来安排的：
- 赛季结束进行休息
- 重新打好基础
- 进入赛季

公路自行车运动，作为一个耐力项目，有氧能力自然是比赛的基础体能。而比赛的关键获胜能力通常是无氧能力。这样也就把年度训练清洗地分成了几个部分，每个阶段有着各自的训练重点。
