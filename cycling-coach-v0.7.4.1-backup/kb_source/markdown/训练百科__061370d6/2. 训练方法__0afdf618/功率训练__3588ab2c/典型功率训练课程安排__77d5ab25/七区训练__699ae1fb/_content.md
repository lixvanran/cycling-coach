
# 七区训练

### 七区训练

7区，也就是冲刺训练。作为终点冲刺的能力，通常不需要在短时间内重复多次。因此，训练过程中，应该保证每次冲刺就全力，而每次冲刺后都要充分休息。

对于大多数业余车手，随机的冲刺通常就足够了。如果你发现你的冲刺进步很快，或者希望在终点跟对手拼杀，那么，规律、科学的冲刺训练课程更有效。

需要注意的一点是，重点冲刺通常是在几个小时的拼争之后进行的，因此，抗疲劳能力非常重要。

此外，冲刺通常是采用离坐的姿态完成，踩踏动作与坐踩差别很大，需要单独进行训练。而且，由于对上肢和躯干的力量要求也比较高，因此，如果想要练出完美的冲刺，需要进行相应的力量训练。
