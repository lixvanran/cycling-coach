
# 如何绑定TrainingPeaks？

### 如何绑定TrainingPeaks？

 下载并安装"Wahoo ELEMENT companion" 软件，打开并登陆后，在"Profile"页面，选择"Linked Accounts"，然后选择"TrainingPeaks"，验证登录即可。
