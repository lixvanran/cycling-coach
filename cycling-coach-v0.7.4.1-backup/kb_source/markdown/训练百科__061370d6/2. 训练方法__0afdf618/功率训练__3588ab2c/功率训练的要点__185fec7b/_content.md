
# 功率训练的要点

功率训练和使用其他训练工具进行训练一样，都要保证训练课的充分刺激。

由于功率可以即时地反应训练刺激的量和强度，配合功率训练强度区间，很容易知道在练什么，因此安排训练课程的方式是多种多样的。

不过还是有一些注意事项：
- 确立要训练的参考点。最基本的就是FTP、VO2max。由于个体差异很大，无氧和有氧能力、耐力、抗疲劳能力都不一样，需要找到符合个体特点的训练参考点。同时还可能需要根据训练/比赛目标，做出调整。
- 保证足够的刺激。一些书上会告诉我们，比如，通过功率的下降来判断，训练是否已经做到位。但是，当一次间歇的功率较标准组下降比如10%的话，是不是训练刺激就正合适，并没有一个绝对的结论。通过长期的训练，找到最符合自己的训练模式很重要，但是这确实有难度。在不知道的情况下，可以以功率下降比例作为一个参考点。
- 结合心率、rpe等其他工具，综合评估训练负荷，以及身体的恢复情况。
- 不要忽视踏频在骑行过程中，对于产生功率的意义。
- 功率计帮我们把骑行数据量化了，但是生活中有很多事情无法量化，但是都会对人、继而对训练产生影响。因此，不要只看功率数据。
