
# 如何从Wahoo ELEMNT和ELEMNT BOLT同步训练记录到TrainingPeaks？

### 如何从Wahoo ELEMNT和ELEMNT BOLT同步训练记录到TrainingPeaks？

使用 "Wahoo ELEMNT companion" 软件，设置将课程自动同步到TrainingPeaks。首先，在"Profile"页面，选择"Linked Accounts"，然后选择"TrainingPeaks"，登录验证后，即可设置。
