
# 碳水化合物

### 碳水化合物
- 在人体内分解，提供日常活动的能量。训练和恢复都需要碳水化合物提供能量。高强度训练更加重要。如果缺乏，可能会“撞墙”，即突然感觉非常疲劳。这说明没有糖原了，称之glycogen debt。可能感觉眩晕、疲倦、头疼、愤怒或悲伤。骑行速度被迫变慢，依靠消耗脂肪和肌肉提供热量。
- 很多食物都含有碳水化合物，主要包括面包、麦类、水果、饼干、薯条、蔬菜。碳水化合物就是淀粉和糖，分解成糖原。
- 应选择少加工、富含营养的食品，也就是更天然的食品。
- 健康的碳水化合物，如新鲜水果和全麦食品，还提供纤维。纤维有助于消化吸收。
- 日常营养摄入，55-65%为碳水化合物。单糖和多糖食品都应摄入。
- 转化率速度更快，更彻底。帮助脂肪彻底燃烧。碳水化合物不足，身体为了维持红细胞和神经细胞的供能开始大量分解肌肉和脂肪。在这种情况下脂肪不完全分解的产物（乙酰辅酶A）大量堆积并形成酮体（ketone），会造成疲劳、恶心、口臭、食欲不振。人体内储存的葡萄糖足够人一天不动使用，或90分钟的中高强度运动。因此，超过90分钟的骑行必须补充能量。
- 碳水化合物和蛋白质一起吃会减慢碳水化合物的吸收速度。或者说，和蛋白质一起，碳水化合物的GI降低。
- 耐力运动运动员每天碳水化合物的推荐摄入量是7-10g/kg体重
- 训练前应摄入1-4g/kg体重的碳水，训练后30-40分钟是糖原恢复窗口期，应尽快摄入1-2g/kg体重的碳水。随后的每1-2h摄入1-2g/kg体重的碳水进一步辅助糖原恢复。
