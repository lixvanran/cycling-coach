
# 概述

训练本身，和比赛一样，是一项团队项目。在训练的所有要做的事情之中，很多事情都可以或者应该需要其他专家的参与和帮忙，身边的人也从其他方面让你可以完成训练，他们就组成了你的训练支持团队。

最常见的一位团队成员就是教练员。教练员可以辅助运动员制定训练计划，分析训练数据，提供训练和比赛建议。

第二常见的团队成员，可能是bike fitter。训练开始前，确保车辆设定正确，是减伤提效的重要手段。

机械师、运动康复师、治疗师、体能师、心理咨询师也都可以帮忙解决日常训练的问题。

车队里还会有车队经理、营养师、按摩师、数据分析师、睡眠师等等。

此外，你的家人，车队队员、支持你骑车的朋友，以及日常生活中，对你骑车训练比赛有帮助的人，都可以算作这个团队中的一员。
