
# 概述

### 概述

如果说训练目标是灯塔，那么计划就是航线，告诉你然后走才能到达目的地。训练计划就好像一份粗略的作战计划，告诉你每个阶段应该要做什么，才能打胜仗。

常规的月计划，也就是中周期的安排，每个阶段1-3个月，最长的两个阶段是基础期和强化期，是能力提升的两个主要阶段，一般采用2-3周休息一周的方式，来保证身体有足够的时间休息、适应。前面的准备期是让身体做好准备。能力提升后，当然就是准备去比赛了。这就是赛季的一般安排。适合大部分运动员。

还有一些特殊的安排方式，周期模型，可以匹配运动员的一些特殊要求。

做好月度计划后，每周的安排相对就容易多了，因为此时已经明确了最近的训练目标，只需要安排相应的课程就可以了。一个重点就是如何保证训练与恢复的平衡，既要有足够的训练刺激，让能力提高，又要给身体留出足够的时间休息。

有了一份详细可行的训练计划，每天就不用为练什么而发愁了。
