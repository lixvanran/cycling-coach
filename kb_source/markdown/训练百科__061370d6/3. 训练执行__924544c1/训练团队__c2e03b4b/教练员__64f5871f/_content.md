
# 教练员

·国际教练联合会(International Coach Federation,简称ICF)的定义：

执教的过程是教练(Coach)与自愿被教练者(Coachee)在人格深层次的信念、价值观和愿景方面相互联结的一种协作伙伴关系。通过一个持续的流程，“挖掘潜能、目标设定、明确行动步骤”，实现卓越的成果。教练也是知识的载体，是“专注于发展人的潜能”的一种技术和形式。

### 教练员的作用

一提到自行车教练员，很多人的脑海中可能会出现一个高大魁梧的男人，一边开着车，一边把头伸出窗外，冲着自己的队员大喊“快点骑”，还疯狂地按着喇叭。比赛当中的教练形象貌似也差不多，但其实教练还有很多工作要做。

首先就是要选材，挑选好的队员可以说是车队成功所迈出的第一步。一般来说，教练（不光是自行车教练）都会“看相”，眼睛都跟X光机似的，能看到骨头里。

然后就是制定训练计划。如果是国家队的教练，那么他是有任务的，所以训练计划他说了算。但如果是面向大众的教练，那么制定训练计划通常是协商共同完成的。

有了训练计划之后，就开始训练了。运动员要写训练日记，教练其实也要写，还要阅读运动员的反馈，不断对计划进行调整和优化，以达到之前两个人商量好的训练目标。那么，这期间免不了要进行各种数据分析。特别是有了功率计，一秒钟几十个数据。

教练员的任务绝不是仅仅随便给出一份训练计划，而要对你的训练、生活，方方面面，进行关注、监督，并进行干预。如果说运动员只负责骑车、吃饭和睡觉，那么生活和训练中的其他所有事情都要由教练来负责。因此，请不要低估一名教练员的工作量。

及时与他们沟通，让他们了解你的一切（真的是一切），这对于他们帮你健康科学地制定训练计划，真正取得训练效果都非常关键。

重点是，训练的主体是你，教练员不能帮你做练习。因此，只有你想练，教练才能真正帮助你。这也是很多人对教练的一个错误认识，认为有了教练自己就一定可以变强。事实上，教练不能让你骑得更快！而是当你想要变快，教练辅助你更有效地实现目标！

当你非常积极的去训练，还经常给自己加量，此时，教练的一个非常重要的工作就是“叫停！”作为运动员，骑车就像吃饭一样，一天不骑饿得慌。然而，如果没有足够的休息，不仅成绩提高不了，还会伤害到身体。如果教练发现某个队员最近特别刻苦，每天10趟妙峰山，那就要发挥“家长”的功能，让他立即停止训练，倒立一个小时让血液回流一下（开玩笑）。

刚才我用到“家长”这个词，有些人可能觉得占便宜，其实不是的。无论是国内的体校还是国外的体校（当然人家不这么叫），都是一个教练把一群孩子带大，可能直到晋级到更高级的队伍。在这段时间，教练除了管训练，还要管吃喝拉撒睡。特别是刚开始练的青少年，13、14岁，今天感冒明天闹肚子的，都是家常便饭。出现问题，他们首先要找的肯定是教练。真的哪个孩子卧床休息，教练还得前前后后的照料。

此外，像心理辅导、日常管理、赛前准备、战术分析等等，教练并不是个简单的工作。如果这个教练想法激进，肯定还想要研究出更有效的训练方法。
